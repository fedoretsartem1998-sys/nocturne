# Ноктюрн — сайт квіткарні

Демо-магазин квітів на Next.js і Tailwind. Підходить як портфоліо і як шаблон: під нового клієнта перебрендовується за кілька хвилин.

## Що вміє

- **Каталог** із фільтрами за приводом, кольором, видом квітів і ціною, плюс сортування.
- **Сторінка букета**: три розміри з різною ціною, склад, «додати в кошик», обране.
- **Конструктор букета**: клієнт обирає квіти, колір, кількість, пакування і стрічку, а букет малюється наживо разом із ціною.
- **Кошик і оформлення**: кур'єр або самовивіз, дата і двогодинний слот (минулі слоти на сьогодні вимикаються), текст листівки з прев'ю, анонімна доставка, сторінка «Дякуємо».
- **Обране** (сердечка).
- **Дві мови**: українська та англійська, перемикач у шапці.
- **Адмін-панель** (`/admin`, пін `1234`): додати, змінити, сховати або видалити букет, склад, фото, ціну; список замовлень.
- **Ілюстрації букетів генеруються кодом** зі складу (`src/components/bouquet`). Якщо в адмінці вказати посилання на фото, замість ілюстрації показується фото.
- Анімація розпускання на головній, поява блоків при скролі, повага до `prefers-reduced-motion`, адаптив до 360 px.

## Як перебрендувати під клієнта

1. **`src/brand.config.ts`** — назва, слоган, місто, адреса, телефон, email, соцмережі, години роботи, валюта, вартість доставки і поріг безкоштовної, часові слоти, пін адмінки і всі кольори сайту.
2. **`src/lib/products.ts`** — стартовий каталог (або заповніть через адмінку).
3. **`src/lib/catalog.ts`** — квіти для конструктора з цінами за стебло, пакування, приводи.
4. **`src/lib/i18n.ts`** — усі тексти сайту українською та англійською.
5. **`src/app/icon.svg`** — іконка вкладки.
6. Шрифти підключені в `src/app/layout.tsx` (Prata для заголовків, Onest для тексту), змінні шрифтів — у `src/app/globals.css`.

## Важливо про демо

Каталог, кошик, обране і замовлення зберігаються в `localStorage` браузера. Нічого не надсилається на сервер, оплата не підключена. Для реального клієнта наступні кроки:

- база даних для каталогу і замовлень (Supabase, Vercel Postgres або Sanity як CMS);
- справжня авторизація для адмінки замість піну;
- сповіщення про нові замовлення (Telegram-бот або email);
- оплата (LiqPay, Monobank, WayForPay);
- справжні фото букетів.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшн-збірка
```

Деплой: імпортуйте репозиторій на vercel.com, налаштування за замовчуванням підходять.
